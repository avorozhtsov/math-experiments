16. Приближение многочленами. Многочлены Чёбышева.

В программе Wolfram Mathematica экспериментируем с приближением функции многочленами: равномерные и неравномерные сетки. 
Многочлен Чёбышева степени N – это многочлен с фиксированным старшим коэффициентом, максимум значений которого на отрезке [-1,1]  минимально (minmax задача).
Теорема о равенстве модулей экстремумов у решения задачи minmax.
