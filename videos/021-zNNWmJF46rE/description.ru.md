Комбинаторика – замечательная стартовая точка для входа в математику + программирование. Правильные скобочные выражения – интересный комбинаторный объект, на примере которого можно познакомиться с базовыми приёмами программирования и комбинаторики:

01:22 Рассмотрение расширенного параметрического множества задач
06:41 Понятие стэка 
10:48 Динамическое программирование сверху (рекурсия + memoization)
11:30 Получение производящей функции по рекуррентной формуле
15:25 Анализ асимптотики роста последовательности чисел
20:23 Вычисление Pi с помощью чисел Каталана
22:45 Оценка времени работы функций
24:01 Выводы

Решите три задачи на каком-нибудь языке программирования:
Задача 1: Напишите функцию, определяющую правильность скобочного выражение.
Задача 2: Напишите функцию, определяющую количество правильных скобочных выражений длины 2n.
Задача 3: Напишите функцию, генерирующую правильные скобочные выражения длины 2n.
