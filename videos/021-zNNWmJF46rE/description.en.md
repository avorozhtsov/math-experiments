Try to solve three problems in some programming language:

Problem 1: Write a function to determine the correctness of a parenthetical expression.
Problem 2: Write a function to determine the number of correct parenthetical expressions of length 2n.
Problem 3: Write a function to generate correct parenthetical expressions of length 2n.

How interesting are these problems? If they captivate you and you find yourself programming late into the night, then you're on the fast track to becoming a programmer.
