Сегодня от простых наблюдений о степенях простых чисел в числах Каталана мы дойдём до неравенств Чёбышева:
  A * n/log(n)  ≤ π(n)  ≤  B * n / log(n)
где π(n) – количество простых чисел меньше либо равно n.
Мы нарисуем красивые фрактальные графики степеней простых чисел в произведении первых n  чисел Каталана. 
Узнаем про производящие функции треугольников.
Продолжаем изучать Wolfram Mathematica – будем активно использовать функции Series, Accumulate, Tally.
