Различные тождества для чисел Фибоначчи:
1) F[0]^2 + F[1]^2 + F[2]^2 + F[3]^2 + .. + F[n]^2  = F[n] * F[n+1]
2) F[0] * F[n] - F[1] * F[n-1] - F[2] * F[n-2] + .. + F[n] * F[0] = F[n+1], n = 2m.
3) Пусть C[n] :=  F[0] * F[n] - F[1] * F[n-1] - F[2] * F[n-2] + .. + F[n] * F[0] ;
  тогда C[n] + 2*C[n-1] = (n+1) * F[n+1]
