## Repository structure / Структура

- `videos/<number>-<YouTube ID>/`: localized titles, descriptions, current tags, captions and thumbnails.
- `yt-channel/`: original author Mathematica notebooks; shared notebooks are linked rather than duplicated.
- `thumbnail-sources/`: recovered editable original thumbnail files.
- `catalog.json`: machine-readable index.
- `ASSET-AUDIT.md`: source coverage and gaps.

Descriptions retain the existing text and chapter timestamps. Repository links are additive. Audio masters and intermediate API logs are deliberately stored outside Git.
